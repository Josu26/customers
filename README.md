# Customers — Exploratory Dataset Notebook

**Historical data exploration · Dataset and notebook**

This small repository contains a tabular customers dataset (`Customers.csv`) and a Jupyter notebook (`Untitled0.ipynb`). It is an exploratory learning artifact, not a customer-management system, production data product or a live business dataset.

## Files

- `Customers.csv` — columns include customer ID, demographic and spending-related fields.
- `Untitled0.ipynb` — exploratory notebook. The notebook's outputs, assumptions and runtime have not been independently verified in this review.

## Responsible reuse

The original data source, permission to redistribute, collection method and licence are **not documented here**. Do not assume this is a licensed or representative real-world dataset. Do not use it to make decisions about individuals or infer personal traits. Confirm provenance and reuse rights before redistributing or extending the dataset.

## Status

Historical learning artifact. Retained for transparency, not featured as a current flagship project.
